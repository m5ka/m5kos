# 👩‍💻 m5kos

**m5kos** is (or, will be) a tiny kernel implemented in rust.

it's mostly just a learning project to get myself more familiar with rust and with the low-level fundamentals of kernel programming.

## try it out

everything can be done with cargo make.

```sh
cargo make run  # build, package into an iso and launch qemu
cargo make iso  # just package the iso
```
